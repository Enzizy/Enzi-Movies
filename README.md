# Enzi Movies

Enzi Movies is an Android app for browsing movies and TV shows and watching them on your phone or tablet. Maintained by [Enzizy](https://github.com/Enzizy).

[Download the Android APK](https://github.com/Enzizy/Enzi-Movies/releases/latest)

## Watch

- Browse the TMDB catalog with your own read access token.
- Open fullscreen playback in one tap and switch sources using **Servers**.
- Play local videos and direct HTTPS MP4 and HLS links.
- Download direct media files for offline playback.

Enzi Movies supports Android 7.0 and newer on ARM64, ARMv7, and x86_64. See the [Android setup and build guide](android/README.md).
